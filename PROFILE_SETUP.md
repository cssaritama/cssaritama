# GitHub Profile README Setup

GitHub displays a profile README when you create a **public repository with exactly the same name as your username**.

For this profile:

- Repository name: `cssaritama`
- Visibility: Public
- Main file: `README.md`

## Upload

```bash
git init
git branch -M main
git remote add origin https://github.com/cssaritama/cssaritama.git
git add README.md
git commit -m "feat: add AI systems architecture profile"
git push -u origin main
```
